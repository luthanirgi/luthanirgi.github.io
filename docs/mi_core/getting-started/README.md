# Getting started

Three short pages take you from an empty server to writing code against mi_core.

1. [Installation](installation.md) covers the resources you ensure, the load order, and the database import.
2. [Configuration](configuration.md) walks through the settings that matter on day one.
3. [Migrating from qbx or qb](migrating.md) explains what changes for existing resources. For most servers the answer is nothing.

If you already run a qbx or qb server, installation is the only page you strictly need.
