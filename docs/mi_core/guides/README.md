# Guides

Task focused walkthroughs. Each one builds something small and complete so you can copy the shape into your own resource.

- [Your first resource](first-resource.md) writes a working command that reads the player and pays them.
- [Players and money](players-and-money.md) covers the player object, balances, and safe money changes.
- [Jobs and gangs](jobs-and-gangs.md) covers setting jobs, grades, duty, and reading who is on duty.
- [Donation refund](donation-refund.md) turns on the optional feature that preserves donation assets across a character delete.

Every example runs on the server unless it says otherwise.
